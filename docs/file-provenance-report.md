# File Provenance Report

This report records what is project-authored, what is generated by the project
pipeline, and what was imported or downloaded from external sources.

Scope:

- Branches: local `Iñaki` and remote/Nikhef-sync `origin/Iñaki`.
- Policy: commit this file and push `Iñaki`; then both local and Nikhef copies
  contain the same provenance report after `git pull origin Iñaki`.
- Coverage: tracked files only, as returned by `git ls-files`.
- Excluded by design: ignored local/editor/build artifacts such as `.obsidian/`,
  `.vscode/`, `__pycache__/`, `.venv/`, raw `.root`, `.hepmc`, `.lhe.gz`, and
  large Condor production directories.

## Provenance Classes

| Class | Meaning |
|---|---|
| Project-authored | Written by Iñaki, the project team, and/or Codex for this repository. External papers/software may have informed the implementation but the file text/code is ours. |
| Project-authored setup | Same as project-authored, but specifically for local/Nikhef setup. |
| Project-authored report draft | Draft report text assembled by the project from the repository methods, results, and cited literature. |
| Project-authored bibliography | Bibliography compiled by the project from cited references. |
| Generated/project config | Generated by our helper scripts or hand-locked as project campaign configuration. |
| Generated project result | Output produced by our project analysis/validation scripts. |
| Generated + external context | Output produced by our plotting scripts using project results plus external AxionLimits context curves. |
| Derived external data | Data produced by transforming an external public dataset into project units. |
| Imported/vendor | File copied from an external software/model/detector source. |
| Imported literature PDF | Downloaded paper kept locally as a reference. |
| Adapted external | Started from an external source and modified for this project. |

## Executive Summary

Project-authored core files:

- `analysis/`, `condor/`, `docs/`, `env/`, `mc/`, and `theory/` code and
  guides, except explicitly listed imported/vendor files.
- Detector cards `mc/delphes_cards/delphes_card_Belle2.tcl` and
  `mc/delphes_cards/delphes_card_belle2_validation.tcl`.
- Project-specific adaptation `mc/delphes_cards/delphes_card_IDEA.tcl`.

Imported/downloaded files:

- Literature PDFs in `literature/`.
- FeynRules-generated UFO files in `models/ALP_linear/SM_alp_UFO/`.
- FCC IDEA reference card `mc/delphes_cards/fcc_idea/card_IDEA_winter2023.tcl`.

Generated or derived files:

- `results/belle2_closure/*` from the Belle II closure workflow; the target CSV
  is derived from AxionLimits.
- `results/fccee/*` projection, efficiency, background, classification, and plot
  outputs from the project pipeline.
- `theory/predictions/theory_grid.csv` from `theory/predictions/predict_grid.py`.
- Condor point lists in `condor/*.txt`.
