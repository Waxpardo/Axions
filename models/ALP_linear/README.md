# ALP_linear UFO model

Place the public `ALP_linear` UFO model files in this directory. Before generating events, inspect: `particles.py` for the ALP particle label and PDG id. `parameters.py` and `couplings.py` for the photon coupling parameter name.And finally the width convention used by the UFO, then compare with MadGraph
  `compute_widths` before using lifetime-dependent selections.
